# CRM Analytics for Fast Food

Веб-приложение (CRM-система с модулем математической аналитики) для предприятия быстрого питания на **Java 17 + Spring Boot 3 + MySQL + Thymeleaf + Bootstrap + Chart.js**.

Проект разработан в рамках курсовой работы с интеграцией 7 математических и вероятностных моделей непосредственно в информационную систему предприятия. Все вычисления выполняются в Java на основе реальных данных из базы данных.

---

## Основные возможности

- **Главная панель (Dashboard):** выручка, заказы, средний чек, себестоимость (COGS), общие расходы, валовая прибыль, операционная прибыль, прогноз выручки на завтра, графики динамики продаж, заказов по часам суток и топ-товаров.
- **Модуль заказов:** список, пагинация, поиск, фильтрация по дате, подсчёт общей суммы, добавление/редактирование заказа с несколькими позициями или ручной суммой.
- **Модуль товаров:** ассортимент, цены продажи, учёт количества продаж, статус активности.
- **Ингредиенты и себестоимость:** справочник сырья, технологические карты блюд и автоматический расчёт себестоимости по формуле $C = \sum(q_i \times p_i)$.
- **Модуль расходов:** учёт по 6 категориям (аренда, зарплата, коммунальные услуги, закупка продуктов, интернет и связь, прочие расходы) с разделением на постоянные и переменные. Исключён двойной учёт закупок продуктов и COGS.
- **Модуль персонала:** сотрудники, смены, генератор графика на период, учёт отработанных часов, производительность $E = N / H$.
- **Модуль математической аналитики (7 моделей):** средние показатели, распределение Пуассона, скользящее среднее с сохранением прогноза, маржинальная прибыль, точка безубыточности (в шт. и сомах), точность прогноза MAE, производительность персонала.
- **Финансовые отчёты:** выручка $R$, себестоимость $COGS$, валовая прибыль $GP$, операционные расходы $OE$, операционная прибыль $OP$ с группировкой по дням, неделям и месяцам.
- **Импорт CSV и демонстрационный режим:** импорт данных из CSV с валидацией и защитой от дубликатов; встроенный демонстрационный набор (~400 заказов за 21 день), полностью изолированный от реальных данных.

## Технологический стек

- **Backend:** Java 17, Spring Boot 3.3.5, Spring MVC, Spring Data JPA, Spring Security, Bean Validation
- **База данных:** MySQL 8 (основная, профиль `mysql`) / H2 (встроенная для запуска без MySQL, профиль `h2`)
- **Frontend:** Thymeleaf, Bootstrap 5.3.3, Bootstrap Icons 1.11.3, Chart.js 4.4.1 (подключены локально через WebJars — работают без интернета)
- **Сборка и тесты:** Maven Wrapper (`mvnw.cmd`), JUnit 5, Spring Boot Test, MockMvc

## Быстрый запуск на Windows

### Вариант 1. С базой данных MySQL (основной)

1. Установите **JDK 17** и **MySQL 8**.
2. Создайте базу данных вручную (необязательно — приложение создаст её автоматически благодаря `createDatabaseIfNotExist=true`, либо выполните скрипт):
   ```sql
   SOURCE sql/schema.sql;
   ```
3. По умолчанию используются настройки из `src/main/resources/application-mysql.properties`:
   - URL: `jdbc:mysql://localhost:3306/fastfood_crm?...`
   - Пользователь: `root`
   - Пароль: `root`
   При необходимости задайте переменные окружения `DB_URL`, `DB_USER`, `DB_PASSWORD`.
4. Запустите приложение из корня проекта:
   ```powershell
   .\mvnw.cmd spring-boot:run
   ```

### Вариант 2. Локальный запуск без установки MySQL (встроенная БД H2)

Если MySQL не установлен, можно запустить проект с файловой базой H2 (в режиме совместимости `MODE=MySQL`):

```powershell
.\mvnw.cmd spring-boot:run "-Dspring-boot.run.profiles=h2"
```

База сохранится в папке `./data/fastfood_crm.mv.db`.

### Запуск в Visual Studio Code (Windows)

1. Установите расширение **Extension Pack for Java** и **Spring Boot Extension Pack**.
2. Откройте папку проекта в VS Code.
3. Откройте файл `src/main/java/kg/fastfood/crm/FastFoodCrmApplication.java` и нажмите **Run** (или выполните команду запуска в терминале VS Code).
4. Откройте в браузере: `http://localhost:8080`

## Демонстрационные данные и импорт CSV

При первом запуске на пустой базе автоматически загружается демонстрационный набор (~400 заказов за 21 день, 11 блюд, 17 ингредиентов, расходы, сотрудники и смены).
- В шапке отображается текущий режим: **Демо-данные** или **Реальные данные**.
- В разделе **Настройки и импорт** можно:
  - переключиться в режим реальных данных;
  - удалить демонстрационные данные без потери реальных записей;
  - импортировать собственные CSV-файлы (готовые примеры лежат в папке `sample-data/`, а шаблоны можно скачать прямо из интерфейса).

## Запуск тестов

```powershell
.\mvnw.cmd test
```

Включены модульные тесты для всех 7 математических моделей (`src/test/java/kg/fastfood/crm/math/`) и интеграционные тесты (`IntegrationCrmTest`), проверяющие работу БД, расчёты моделей, CSV-импорт, изоляцию демо-данных, авторизацию и рендеринг всех страниц.
